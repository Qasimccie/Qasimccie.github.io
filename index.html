SD-WAN

Faster, cheaper and more reliable branch connectivity

I design SD-WAN that uses every link you pay for and keeps critical apps running when one fails.

  • Application-aware steeringVoice, ERP and cloud apps take the best path automatically.
  • SLA health checks and failoverLatency, jitter and packet loss are measured continuously, and traffic moves when a link degrades.
  • Secure overlaysEncrypted IPsec tunnels over MPLS, broadband and LTE with BGP on top.
  • Migration from legacy WANPhased cut-over from MPLS-only or DMVPN designs with a rollback plan.

import requests

# Pull the config from each FortiGate via REST API

    r = requests.get(
        f"https://{fw['ip']}/api/v2/monitor/system/config/backup",

        headers={"Authorization": f"Bearer {fw['token']}"},
    )
    save(fw["name"], r.text)
